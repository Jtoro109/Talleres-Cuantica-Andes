## 📂 Contenido del Repositorio

- **`Hallar PI/`**: Taller de estimación de $\pi$ mediante el Método Montecarlo y la Aguja de Buffon (`T1.ipynb`).
- **`centroColombia/`**: Taller del Centro de Colombia y EE. UU. utilizando el Algoritmo Naïve (`centroColombia.ipynb`).
- **`centroColombiaEficiente/`**: Taller optimizado del Círculo Mínimo Contenedor (MEC) usando el Algoritmo de Welzl ($O(n)$ esperado) y comparación de rendimiento vs Naïve (`centroColombiaEficiente.ipynb`).
- **`dijkstra/`**: Taller de Ruta Más Corta desde San Gil hasta Ipiales mediante el Algoritmo de Dijkstra, análisis de variación de $d$ y comparación vs Floyd-Warshall (`dijkstra.ipynb`).
